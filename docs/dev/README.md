# EvoKit Development Notes

Internal records of how the project is being built — milestones, phase-by-phase history, and
bug tracking. For user-facing how-to guides, see [../tutorials/](../tutorials/).

| Document | Purpose |
|---|---|
| [roadmap.md](roadmap.md) | Milestones: what's **done** and the **to-do** list, grouped by area, with a "how to pick up a task" guide. |
| [changelog.md](changelog.md) | Detailed, timestamped phase-by-phase implementation log (every task, every verification). |
| [bugfixes.md](bugfixes.md) | Defects found & fixed, plus known/open issues. |

Workflow when adding something: implement it → update [changelog.md](changelog.md) with a new
phase → tick the item (or add follow-ups) in [roadmap.md](roadmap.md) → log any defect in
[bugfixes.md](bugfixes.md).
